# Overview

This project is a Task Management Application designed to help users efficiently organize and manage their daily tasks. It provides secure user authentication and a complete task management system with CRUD (Create, Read, Update, Delete) functionality.The application is built using a modern web framework and follows best practices for security, scalability, and clean code structure.

Features
- User Authentication
- User registration and login system
- Secure password hashing
- Authentication using JWT / session-based system
- Protected routes for authorized users only

Task Management
- Create, view, update, and delete tasks
  
Each task includes:
- Title
- Description
- Status
- Action (view,Edit,Delete)

Front-End
- Responsive UI built with Bootstrap
  
Pages included:
- Login / Register
- Task List 
- Task Detail View

Back-End
- RESTful API architecture
- API endpoints for:
- User authentication
- Task CRUD operations
- Integrated with database (MySQL)
